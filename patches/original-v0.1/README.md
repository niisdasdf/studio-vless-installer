此前发布的 Studio VLESS 0.3 是另写的安装器，偏离了“保留原脚本、只修隐患”的要求。复核确认其自动 UFW 放行可能扩大已有的来源限制，且缺少原版修改 UUID、卸载和其他协议菜单；已撤回使用推荐。旧固定下载地址仍能访问，不应继续运行旧安装命令。

本目录直接以 dabadabader/install 的固定脚本为基线修改，不沿用上述 Python 安装器。

## 保留的操作

原 1–9 菜单、VLESS TCP Reality / VMess WS / Shadowsocks、随机推荐空闲端口、手动输入端口、默认握手域名、自动生成凭据、分享链接、终端二维码、修改端口、修改 UUID/密码、BBR、卸载和 `menu` 入口均保留。配置仍使用 `/etc/sing-box` 及其 JSON 分片。

随机端口在安装或主动修改时选定，重启不会自动轮换。保留随机端口是为了保留原操作习惯，不代表其更抗封。

## 针对明确问题的改动

| 原问题 | 修补行为 |
| --- | --- |
| 打开菜单即清理未知 JSON 并重写配置 | 菜单退出不动配置；仅明确选择变更才进入修改流程；不删除未知分片 |
| 直接覆盖总配置，失败只有提示而无真实恢复 | 候选文件先合并、再经 sing-box 检查；通过后原子替换；失败恢复备份及原服务状态 |
| 修改 JSON 失败仍可能显示成功 | JSON 编辑失败立即停止；不使用固定临时文件名 |
| 下载程序未校验、信任可变第三方版本信息 | 固定 sing-box 1.14.3 及官方归档 SHA256；包括后备下载来源在内均须通过同一固定摘要验证 |
| `menu` 每次执行远端 main | 保存并调用同版本本地脚本；不自动拉取新代码 |
| 默认文件权限与可预测临时目录 | 私有目录、严格权限、随机临时目录、并发锁；二维码与修改凭据不把完整秘密传入外部程序参数 |
| 修改全局 APT 源和整份 sysctl | 不替换软件源；BBR 使用单独文件，仅应用本次参数 |
| 接管未知旧安装、删除整个工作目录 | 拒绝覆盖外来服务与未知部署；卸载仅移除受管文件，保留未知文件 |
| 公网 IP 查询失败仍生成无效链接 | 查询加超时和格式检查，失败允许手填；查看链接使用已保存 IP |
| 新增备份无限占空间 | 最多保留 5 份本补丁标记的完整备份；回滚失败备份受保护；空间不足在变更前停止 |

## 安装与使用边界

本补丁面向此前确定的**新 Debian/Ubuntu、systemd、带公网 IPv4 的 VPS**。发行版广度并未沿用原脚本未经验证的全部声明；不自动接管旧脚本或公司现有部署。检测到已有非本补丁管理的 `/etc/sing-box`、服务或 `menu` 时会停止覆盖。

仍保留原来的 root 服务、系统本地 DNS、Reality 参数；没有另加 Vision、DoH、非 root 服务、自动防火墙放行。商家安全组及主机防火墙须允许选定端口。VLESS Reality 使用 TCP；Shadowsocks 使用范围还涉及 UDP。

Reality 密钥自动生成，不需要申请自己的域名证书。此原脚本本来没有 HY2、ACME 证书申请/续期或核心升级菜单；本补丁没有虚构这些功能。

入口必须先把脚本下载到普通文件再执行，不能继续用原来的 `bash <(curl ...)` 形式，否则无法可靠保存本地 `menu`。同目录的一键下载命令会自动完成这一步，用户无需手动上传。其用途是新 VPS 部署验收；没有真实 VPS 的测试结果。

失败恢复涵盖受管文件、服务状态和本次 BBR 参数；已经安装的系统依赖包不会自动卸回。未知旧备份不自动删除，受保护备份需要先处理恢复问题。备份包含凭据，应保持私有。

## 验收范围

机器可读结果见本目录的 `static-and-unit-results.json` 与 `vm-validation.json`。脚本 SHA256 见 `SHA256SUMS`，这些结果必须对应同一份脚本。

隔离 Debian 虚拟机通过不等于已在商家 VPS、南昌 R3S 或长期运营环境验收。尚未购买真实 VPS，不能声称“零漏洞”“不会被封”或“已经运营验收通过”。
